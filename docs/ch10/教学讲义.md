# 第10章 动态学习与模型辅助控制：教学讲义

本讲义配套实践篇第10章、已执行Notebook与离线交互页面。全部轨迹由作者构造的W-H1充分混合水罐参考环境产生，变量、种子、动作与划分保存在仓库中。使用约定沿用根目录 `RIGHTS.md`。

## 90分钟课堂安排

| 环节 | 时间 | 操作与可交付观察 |
|---|---:|---|
| 状态、动作与扰动 | 10分钟 | 使用图10-2，写出温度、加热功率、环境温度；解释120 s零阶保持的含义。 |
| 完整轨迹划分 | 10分钟 | 使用图10-3和图10-4，核对2条标定、8条训练、3条验证、4条测试轨迹；定位高温和动作扩展。 |
| 训练与多步预测 | 20分钟 | 执行Notebook前4个代码单元；比较8/16单元开发结果及纯数据/残差网络。 |
| 交互预测实验 | 15分钟 | 切换轨迹、模型、预测起点和跨度，导出一个预测窗口CSV；区分沿途误差与h步终点误差。 |
| 候选规划与执行 | 20分钟 | 切换常规、扩展功率、高温初值；查看实际控制回放、候选代价及恒定候选预测。 |
| 回退与讨论 | 15分钟 | 输入域外温度/功率；核对回退请求、实际执行和联锁接管；提交一页证据表。 |

## 交互模块与观察口径

### 多步预测实验

可切换4条独立测试轨迹、3类模型、起点和1～30步预测跨度。浏览器依据Python导出的tanh网络权重实时计算。每个窗口只在起点读取真实温度，随后递推；参考与模型使用相同的实际未来功率和环境序列。

顶部“当前窗口RMSE”以该窗口内全部预测时刻计算，终点误差是最后一个预测状态减参考状态。底部冻结结果表以完整轨迹上的所有可用窗口计算h步终点RMSE；窗口数在1、5、15、30步时分别为180、176、166、151。两类口径分别适用于观察路径和比较跨度。

建议先在常规测试中选择30步，再切换高温初值。保留终点误差增大、方法排序变化等观察。导出的CSV包含轨迹、模型、时间、参考、预测和误差列。

### 闭环规划回放

控制轨迹与候选账本来自Python已经执行的15组闭环：3个工况乘5种方法。页面回放时刻与候选选择联动显示当前状态、实际动作、综合代价、预测轨迹和筛选状态。它呈现冻结实验的执行记录。

候选在12步内保持恒定功率，代价为预测跟踪均方误差加功率与动作变化项。每个时刻只执行所选候选的首项，下一时刻更新观测并重新规划。候选预测与实际完整闭环分别作图，便于识别未来动作变化的作用。

训练域保护只在“域保护残差”策略启用；其余模型规划策略仍执行物理预测温度检查及共同的执行层约束。训练范围使用每个变量的轴对齐边界，样本联合分布见覆盖散点图。

### 适用域与回退

输入温度、功率、环境温度后，实时展示一步预测和训练输入范围检查。域外探索输出保留显示，并说明域保护策略的处理方式。四个预定义检查记录分别为域内观测、高温状态、未知环境和无效观测。

规划层在无可用候选时请求机理反馈，观测无效时请求零功率。执行层在当前观测温度达到80 °C时统一执行零功率，并保留原请求。高温域保护记录包含63次回退请求，其中56次实际执行机理反馈，7次由公共联锁接管；三个数分别记录不同环节。

## 课堂证据表

每组学生提交下表，并附预测CSV或闭环CSV。

| 项目 | 必填信息 |
|---|---|
| 输入条件 | 轨迹/工况、初值、动作范围、环境范围、模型、预测跨度、选定时刻。 |
| 预测结果 | 当前窗口沿途RMSE、终点误差；完整轨迹h步终点RMSE及窗口数。 |
| 控制结果 | 跟踪RMSE、用电量、动作变化、执行温度范围与各事件计数。 |
| 边界条件 | 域检查是否启用；域外状态/动作是否保留；回退请求和执行是否一致。 |
| 解释与扩展 | 当前结论支持的工况；增加噪声、扰动预测误差或真实采样后拟验证的变化。 |

## 用于讨论的实际结果

- 在常规测试的30步终点误差中，残差模型RMSE约0.00059 K，纯数据模型约0.00259 K，已辨识线性机理约1.122 K。参考环境使用精确状态、固定参数和已知未来输入，这些条件共同影响误差量级。
- 高温测试30步终点RMSE中，纯数据模型约0.188 K，残差模型约0.274 K。该测试保留了方法排序改变的实例。
- 扩展功率工况下，域保护残差跟踪RMSE约5.837 K，未启用域保护的残差约3.386 K。保护限制了候选动作的可用范围，跟踪和适用域要求可在同一账本中对照。
- 验证集绝对误差95%分位数形成固定经验包络。每个测试工况使用151个30步窗口统计覆盖。高温测试的两类神经模型覆盖比例均为0%，用于定位此包络在当前外推条件下的适用范围。

这些结果描述作者构造的教学环境。后续可以接入测量噪声、未知扰动、状态估计和真实设备数据，在保持相同字段及评测口径的基础上继续验证。
