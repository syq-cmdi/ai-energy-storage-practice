# 15分钟课堂演示

先让学生预测方向，再显示曲线。教学数据的用途是把误差机制讲清楚；不据此评判某类真实电池或现场算法。

| 时间 | 操作 | 学生应说明什么 |
|---|---|---|
| 0—3分钟 | 保持参考值，画出四段电流工况 | 正电流对应放电，SOC降低；负电流充电 |
| 3—5分钟 | 点击电流偏高，播放至静置段 | 零电流偏移仍被积分，误差线性积累 |
| 5—8分钟 | 分别试容量2.0 A·h与初值85% | 容量误差改变斜率；初值误差整体平移 |
| 8—12分钟 | SOH页依次切换C09—C12与四种方法，放大末段 | 总体MAE不能替代逐电芯和逐时点检查 |
| 12—15分钟 | 窗口页拖到159，先看历史再揭示160标签 | 输入在预测时已可用，目标只在后续评价时使用 |

## 教师核对值

参考末端SOC = 0.8 − (0.6×0.25 + 1.2×0.25 − 0.4×0.25)/1.8 = 0.605556。

- 电流偏高0.02 A：60分钟末误差 −1.111111 个百分点。
- 容量使用2.0 A·h：末误差 +1.944444 个百分点。
- 初值使用0.85：全程 +5 个百分点。
- SOH页面的指标覆盖该电芯155个目标；放大140—160循环不会重新筛选指标样本。
- 经验误差带只为C07选中的窗口网络校准，切换其他方法后禁用带宽选项。

## 课后提交

提交一个SOC导出CSV、一张SVG图、150字解释。解释应区分测量偏差、容量假设与初始状态误差。再选择一枚测试电芯，写出网络和岭回归的MAE，并解释为什么不能由这个例子推断真实电池上网络必然更好。

进阶练习可重新训练去掉温度特征的模型，但应新建输出目录、重新执行完整选择协议，不依据测试分数反复调参。本仓库已做的内阻偏移实验是冻结模型压力测试，不是重新训练后的消融实验。
