# 第9章插图来源与复现

fig09_01_ai.png由OpenAI imagegen在2026-11-14生成，并以相同工具重排为横向教学概念图。它展示工程师、储能设备、资料卡与计算工具，无量化结果。源图与生成说明保存在本地稿件研究记录中。

生成内容描述：精细等距工程插画，白底，蓝色电池柜与青色水罐在左，工程师居中下方，文档与放大镜居中上方，金色计算器在右；证据流指向人员和计算器；无文字、标志或控制设备的箭头。概念图不作为设备结构或真实系统照片使用。

fig09_02至fig09_10均由作者配套Python/Matplotlib脚本生成，提供SVG、PDF和600 dpi PNG。图2流程、图3版本与范围、图4分块、图7主张核验、图9失败恢复为原理图；图5、6、10来自完整实验账本，图8来自明示的代数关系。

复现命令：`python chapters/ch09/plot_results.py`。语料时间轴仅展示2026-01至2028-01，完整有效期以manifest.json为准。图表中的方法颜色、坐标单位与样本分母见正文及teaching_notes.md。
