# 第8章课堂讲义（90分钟）

目标：建立kg/kWh双账本；解释库存调度；核对信息边界与期末条件。

|时间|活动|产出|
|---|---|---|
|0–15 min|手算5 kg/h输入295 kW，15 min产氢1.25 kg|完整功率与质量账本|
|15–30 min|对照按需/日前的晚间库存轨迹|费用变化的时序解释|
|30–45 min|切换需求突增和限电|扰动前库存与累计缺供表|
|45–60 min|扫描40/80/120 kg配置，明确初值同步变化|容量/初始备用因素说明|
|60–75 min|改变温度和Z；导出CSV/SVG|状态换算与调度变量边界|
|75–90 min|运行Notebook和verify；两步解析57元|独立验证记录|

讨论：限电情景中按需策略的库存备用量带来更低缺供；为滚动协调设计备用约束并重新报告费用、缺供与可行性。固定初值单独扫描容量，再固定容量扫描初值。将当前之后的实际观测改变，当前预测保持相同，后续执行按对应实际输入变化。

作业提交：配置、完整账本、6幅以上自绘比较曲线、代码版本、求解状态与一段正面表述的适用条件说明。评价强调物理单位、实验条件、信息时序、完整失败案例与可复算性。
