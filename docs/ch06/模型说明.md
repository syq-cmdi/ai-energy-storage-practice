# 抽蓄教学模型与适用范围

## 状态与守恒

上库有效水量v为状态，下库有效水量为1152000−v m³。上下库等效面积48000/72000 m²，常规毛水头H(v)=200+v/28800 m。水量更新为v[k+1]=v[k]+3600q[k]Δt，q正值为抽水入上库；并网P正值为发电。Δt以小时计，基础值1 h。

相对空有效库容的势能U=ρg[H₀v+0.5(1/A上+1/A下)v²]/3.6e9 MWh，ρ=1000 kg/m³、g=9.81 m/s²。转移平均水头使用起止水量均值处的H，线性水头条件下其几何功与积分一致。电效率在每时段平均水头和恒定流量处评估，属于声明的小时模型。

损失水头h_f=0.001q² m；ηp=0.91−0.10((|q|−40)/40)²−0.06((H平均−220)/40)²，ηg=0.93−0.12((|q|−40)/40)²−0.05((H平均−220)/40)²。抽水P=−ρgq(H平均+h_f)/(1e6ηp)，发电P=ρg|q|(H平均−h_f)ηg/1e6。能量账为输入−输出=势能增加+水力损失+转换损失。

## 可行域与优化口径

流量档位0、±20、±40、±60 m³/s，上库有效水量0—1152000 m³；抽水150 MW、发电120 MW上限，相邻小时平均并网功率变化≤65 MW。初始及末端有效水量576000 m³，初始前及最后时段停机。相反方向之间安排一个完整停机时段。全部24小时电价预先已知，目标仅为售电减购电净收入。

动态规划状态为（水量索引，上一流量档位），上一流量和当前水量可反推上一开始水量与功率。计算自末端可接受集合向前递推；候选边同时满足水量、功率、变化和模式条件。返回值 `optimal_on_grid` 表示所声明有限网格的最优性。连续动作、多机组、启停成本和水锤动态有各自的扩展模型与验证要求。

规则使用320/700元每MWh阈值，并提前检查剩余时段可达终态。规则所用可达性仅依赖物理条件和剩余时间。四种方法共享初末状态，原始流量按完整模型回放；越限日志作为结果的一部分保留。

## 数据和实验边界

20条基础对照来自5工况×4策略；8条额外水头/爬坡、4条额外网格、1条自由末端对照，共33条。基础完整峰谷日同时作为敏感性与网格基点。单小时目标不可达案例另存于failures。

平价日停机、峰谷日定参数与完整模型动作相同、近似模型越限以及粗网格启动受限均保留。循环效率仅在抽水输入大于零且初末水量一致时报告；库存变化存在时另报输出输入比。

现场应用需用库容水位曲线、运行区域、最小稳定流量、转换轨迹、实际价格和水力动态重新校准并验证。压缩空气部分提供质量、温度、压力、内能和储热状态的迁移设计；本数值项目的求解器以抽水蓄能为对象。
