# 第6章数据字典

## experiment.json

根字段 `chapter/version/source/config/names/policies/runtime/runs/failures`。runtime仅记录Python和NumPy版本。每条run拥有唯一id，group为scenario/sensitivity/grid/free_terminal。

| 字段 | 维度与单位 | 定义 |
| --- | --- | --- |
| config | 对象 | 水库面积/库容/初始水量、水头、效率参考值、损失系数、流量网格、功率与变化上限、dt、ρ、g |
| plan | 对象 | 状态、流量序列、目标、Bellman价值、评估边数、状态数、末端目标 |
| flow | 24，m³/s | 正抽水、负发电、零停机 |
| price | 24，元/MWh | 计划开始前已知价格 |
| predicted_power | 24，MW | 对应计划模型的并网功率 |
| power | 24，MW | 完整模型回放并网功率；发电为正 |
| volume | 25，m³ | 上库时段边界有效水量 |
| upper_level/lower_level | 25，m | 水面高程，差值为毛水头 |
| head_boundary/head_mid | 25/24，m | 边界/时段平均毛水头 |
| efficiency | 24，无量纲或null | 对应抽水/发电方向；停机为空 |
| delta_u | 24，MWh | 时段势能变化，可正可负 |
| hydraulic_loss/conversion_loss | 24，MWh | 非负水力/转换损失 |
| violations | 对象数组 | hour、constraint、value、limit、excess，功率类量以MW计 |
| metrics | 对象 | 真实回放摘要，见下表 |
| predicted_profit_cny | 元 | 计划模型净收益 |

| metrics字段 | 单位与口径 |
| --- | --- |
| profit_cny | 元，sum(price×power×dt) |
| pump_energy_mwh/generation_energy_mwh | MWh，输入/输出非负 |
| energy_output_input_ratio | 无量纲，输入大于零时的输出输入比 |
| round_trip_efficiency | 无量纲，输入大于零且初末水量相同；其余为null |
| delta_storage_mwh | MWh，末态势能减初态势能 |
| hydraulic_loss_mwh/conversion_loss_mwh | MWh，整日损失 |
| end_volume_error_m3 | m³，终态与初态水量之差 |
| violation_count | 条，回放记录数 |
| max_ramp_mw | MW，含初始前P=0的最大相邻变化 |

failures保存不可达案例的完整配置、时域、目标与求解状态。`infeasible`时无有效流量计划；网页33条方案均为已生成计划。

## CSV和哈希

`dispatch.csv`有792行数据，列为run_id,hour,price_cny_mwh,flow_m3_s,power_mw,volume_start_m3,volume_end_m3,head_mid_m,efficiency,hydraulic_loss_mwh,conversion_loss_mwh。停机效率为空。浏览器导出当前一条24小时轨迹，表头同其math.js中的csv函数。

`summary.json`保存每条方案配置与指标；`manifest.json`保存experiment/summary/dispatch三个文件的SHA-256。`docs/ch06/reference_summary.json`仅为教学基准摘录。`demo/ch06/data.js`是为离线页面生成的紧凑副本，浮点数保留7位小数。
