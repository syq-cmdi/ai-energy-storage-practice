# 第5章数据字典

全部数据由 `run.py` 生成，时间步为1 h。功率正值表示该功能方向的功率，能量单位为kWh冷量。当前小时负荷请求在时段开始已知并保持一小时。库存包含25个边界点，功率包含24个时段。

| 字段 | 含义与单位 |
| --- | --- |
| `training` / `validation` | 28日训练和7日验证，各自种子独立 |
| `days` | 凉爽、温和、炎热、热浪和温度资格失效情景 |
| `hour` | 时段开始小时0—23 |
| `temp` | 当前实际室外温度，℃ |
| `weather_forecast` | 运行日前发布的24 h天气预测，℃ |
| `load` | 当前负荷请求，kW冷量 |
| `price` | 电能分时价格，元/kWh电能 |
| `id` | 工况、容积、策略、时域、偏差组成的唯一标识 |
| `volume` / `capacity_kwh` | 罐体m³ / 温度情景对应的有效容量 |
| `policy` | `rule`固定规则、`perfect`完美预测、`mpc`实际预测 |
| `horizon` / `bias` | 名义预测小时数 / 未来乘法偏差 |
| `g` / `c` / `d` / `u` | 直接供冷、充冷、放冷、未满足请求，kW |
| `energy` | 时段边界库存，kWh冷量，长度25 |
| `electricity` | 冷机与线性辅助功耗，kW电功率 |
| `flow` | 末端回路总质量流量，kg/s |
| `supply_temp` | 流量加权混合供水温度，℃；无流时为null |
| `plans` | 每次MPC的发布时刻、预测、计划库存与功率 |
| `solver_log` | 求解状态、目标、对偶界、相对间隙 |
| `metrics` | 电费、未满足冷量、加权目标、最高供水温度等 |
| `annual.rows` | 分策略、分容积的加权电费、年化投资、费用和服务不足 |
| `investment_sensitivity` | 投资函数乘0.5、1、2后的同轨迹核算 |

CSV字段 `direct_kw,charge_kw,discharge_kw,unmet_kw` 对应g,c,d,u；`energy_start_kwh,energy_end_kwh` 是同小时两端库存。Python的 `loop_flow_kg_s` 与网页导出的 `flow_kg_s` 均对应回路质量流量；网页CSV保存当前所选24条记录，Python保存全部2712条。

训练种子100—127，验证200—206；测试401—404。温度资格失效与炎热日共享种子403、负荷和天气，只改变储罐出口温度及相应资格和有效容量。它是受控对照。年度权重仅覆盖前四类日且总和365；压力工况频次未赋权。

预测器只在训练数据拟合标准化与岭回归参数，验证集选择alpha=1。实际预测使用发布天气、当前请求及上一小时已知负荷残差；未来实测用于事后评价。`perfect`单独使用未来实际输入。页面数据保留7位小数，完整Python结果保留浮点输出；网页对账容差据此设置。
