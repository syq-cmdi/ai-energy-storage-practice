# 第10章 动态学习与模型辅助控制

从完整轨迹学习“状态、环境、动作→下一状态”，比较机理模型、温度增量MLP与残差MLP，再把它们放入同一个有限候选滚动规划器。提供17条作者构造轨迹、实际训练权重、单步/多步终点误差、验证经验包络、15组闭环对照和明确的域外回退记录。

## 运行

在仓库根目录，使用Python 3.12和现有固定依赖：

```bash
python -m pip install -r requirements.txt
python chapters/ch10/run.py
python chapters/ch10/verify.py
```

核心实验全部在CPU完成，无外部API或密钥。`run.py`重新生成确定种子的轨迹，保存数据哈希、训练模型和完整结果；默认输出到仓库 `results/ch10`，`--out`可以指定另一目录。程序会覆盖该目录中的本章同名结果文件，适合分别指定新目录保留各次实验。实际训练时间应以本机运行日志为准。

交互、绘图与Notebook入口见本章同目录的演示构建脚本、绘图脚本和已执行Notebook。完整的数值实验账本由 `run.py`生成，不随代码重复提交大型运行结果。

## 参考对象与数据合同

沿用第4章W-H1：充分混合、无进出水的水罐，C=418 kJ/K、UA=.010 kW/K、Δt=120 s。校准轨迹采用线性散热；其他轨迹与全部闭环环境加入β=.00012 kW/K²的二次散热。所有参考状态均由独立DOP853积分获得，部署预测器使用解析线性递推和导出的tanh网络。

本章聚焦动作条件学习，状态观测采用参考温度，测量噪声为0。实际传感器、估计器和噪声变化可作为后续实验接入。训练与测试的高温动力学保持同一β方程，附加高温损失开关保持high_loss=False。

| 分组 | 完整轨迹数 | 单条时长 | 区间数 |
|---|---:|---:|---:|
| 线性机理校准 | 2 | 4 h | 240 |
| 神经模型训练 | 8 | 6 h | 1440 |
| 验证与模型选择 | 3 | 6 h | 540 |
| 独立测试 | 4 | 6 h | 720 |

总计17条、98 h、2940个区间、2957个状态样本。每条轨迹的种子、时刻、动作、环境、状态和参考净热量均保存。轨迹ID及随机种子在分组之间分离，预测窗口始终留在原轨迹内。

## 模型与选择

- 机理：用两条β=0校准轨迹的完整温度曲线辨识C和UA。
- 温度增量MLP：`T_next = T + f(T, Ta, u)`。
- 残差MLP：`T_next = F_physical(T, u, Ta) + g(T, Ta, u)`。
- 输入顺序固定 `[T, Ta, u]`。输入均值/尺度与目标均值/尺度只在8条训练轨迹拟合。隐藏层tanh，输出线性，网络输出单位K。
- 两类网络各比较8/16隐单元，α=.0001、L-BFGS优化、种子410+宽度。按3条验证轨迹的15步终点RMSE选择，保存全部候选结果。两类本轮均选16。
- 已辨识机理参数向残差模型提供先验；纯数据网络使用训练状态动作记录。规划阶段的外生信息、候选、目标和约束相同。

| 模型 | 验证15步终点RMSE：8单元 | 16单元 |
|---|---:|---:|
| 温度增量MLP | .008428 K | .003192 K |
| 残差MLP | .003615 K | .002367 K |

模型选择与验证经验阈值在测试评分前写出 `selected_config.json`，已选权重和全部4个开发候选的权重、配置、指标存入可读 `models.json`。代码生成新的模型/数据版本后，应与对应的哈希和结果一同保存。

## 测试结果与经验包络

h步误差指每个合法起点递推h次后的**终点误差**。每步使用该轨迹记录的实际动作与环境，初温取起点参考状态，随后递推使用预测状态。h=1/5/15/30；30步对应1 h，每条6 h测试轨迹有151个合法窗口。窗口存在重叠相关性。

| 测试轨迹 | 机理30步RMSE/K | 增量MLP | 残差MLP |
|---|---:|---:|---:|
| 常规 | 1.121606 | .002586 | .000592 |
| 环境变化 | 1.606715 | .003600 | .000357 |
| 扩展动作 | 2.105916 | .069576 | .062241 |
| 高温初态 | 2.944627 | .187769 | .274064 |

残差模型在高温轨迹上的误差高于增量模型，结果原样保留。训练范围为T∈[30,66.9008]℃、Ta∈[17.4,24.6]℃、u∈[0,1.5] kW。扩大动作和高温轨迹同时报告实际输入出域情况，便于按具体条件解释结果。

验证集绝对终点误差的95%经验分位数采用 `method="higher"`。它与宽度选择共用验证集，属于描述性误差包络；独立区间校准可以通过新轨迹开展。30步半宽分别为机理2.177312 K、增量MLP .012094 K、残差MLP .011030 K。高温测试30步落入比例均为0%；范围变化后应继续评价覆盖。域检查使用变量上下界，与这个经验包络分开实现。

## 有限候选滚动规划

每次枚举公共候选功率，每个候选在H=12步内保持常数，预测24 min，仅执行第一步后重新规划。真实未来环境与目标日程属于本教学任务已知输入，所有规划器共同使用；当前温度观测完全相同。

`J = mean((T_pred - target)^2) + .08 u + .15 (u-u_previous)^2`。

若J采用K²，功率权重单位K²/kW，切换权重单位K²/kW²。该式为教学跟踪代价，电能另按ΣuΔt/3600累计为kWh。温度预测约束15–85℃；执行器对全部策略共同施加功率范围以及观测T≥80℃的零功率联锁。规则基线使用±.4 K滞回开停，与模型规划方法分别登记。

带域检查的残差规划器逐步检查预测输入及下一温度是否落在训练变量的轴对齐盒内。此检查描述各变量范围；训练样本的联合密度需要另行分析。若全部候选失效，按已辨识机理反馈 `C*(target_next-T)/1800 + UA*(T-Ta)`计算请求，投影至公共功率候选；无效观测返回零功率。

| 常规4 h闭环 | RMSE/K | 电能/kWh | 功率总变差/kW |
|---|---:|---:|---:|
| 滞回规则 | 1.721895 | 2.65 | 19.5 |
| 机理候选规划 | 1.369208 | 2.60 | 8.1 |
| 增量MLP候选规划 | 1.319287 | 2.66 | 8.7 |
| 残差MLP候选规划 | 1.319298 | 2.66 | 8.1 |
| 带域检查残差规划 | 1.319298 | 2.66 | 8.1 |

在扩展功率场景中，带域检查的规划器累计排除360个候选，仍有可行候选，因此回退请求和执行均为0；跟踪RMSE为5.837419 K，未加域检查的残差规划为3.385811 K。高温初态场景提出63次回退请求，其中56次执行机理反馈、7次由公共联锁接管。15组闭环均在本实验温度范围内运行；后续工程验证需结合真实设备与完整约束开展。
