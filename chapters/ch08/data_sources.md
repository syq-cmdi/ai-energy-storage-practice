# 来源与许可

教学数据、功率曲线、需求和电价均由作者构造，许可沿用MIT；数值用于模型教学。压缩3 kWh/kg、电解55 kWh/kg等为明确设定的常数。

1. DOE. Gaseous Hydrogen Compression. 2026-06-08更新，2026-11-14核查。支持压缩与入口/出口压力、压比和质量流量的关系。https://www.energy.gov/cmei/fuels/gaseous-hydrogen-compression
2. Johanna Ivy. Summary of Electrolytic Hydrogen Production: Milestone Completion Report. NREL/MP-560-36734, 2004. 引用热值与效率口径讨论，历史商业参数不作为本版设备性能。https://www.energy.gov/documents/36734pdf
3. SciPy 1.15.3 milp官方文档。接口、变量类型、返回状态与最优间隙。https://docs.scipy.org/doc/scipy-1.15.3/reference/generated/scipy.optimize.milp.html
