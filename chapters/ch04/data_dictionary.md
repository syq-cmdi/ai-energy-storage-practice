# 数据字段与生成来源

全部数值由 `run.py` 构造，未加载外部数据集。算法文献不提供本章实验数据。

| 字段 | 单位与形状 | 对齐和用途 |
|---|---|---|
| episode, role | 字符串 | 完整轨迹与划分 |
| time_s / t_s | s，n+1点 | 起点0，固定120 s |
| power / u_kW | kW，n区间 | [t_k,t_(k+1))内保持 |
| ambient / Ta_C | ℃，n区间 | 同输入保持约定 |
| truth / T_ref_C | ℃，n+1点 | 独立参考求解，仅评分 |
| observed / y_C | ℃，n+1点 | 参考温度+噪声+偏移 |
| noise | K，n+1点 | 指定PCG64种子的高斯样本 |
| bias | K，n+1点 | 偏移测试6 h起+1.2 K |
| energy_ref | kJ，n区间 | 独立参考净热流积分 |
| T_physical_C,T_gray_C | ℃，n+1点 | 开环，只用起点观测 |
| T_kf_C,T_ekf_C | ℃，n+1点 | 每步读取观测更新 |

CSV末行输入/环境/参考热量空字段表示无后续区间，不应补出新积分区间。所有轨迹在 `build_data()` 列出初态、种子、时长和机理标签。`test_bias` 与 `test_loss` 共用seed=42，形成严格配对；其他轨迹采用不同种子。

基础参考：C dT/dt = u−UA(T−Ta)。附加散热参考：额外加入−0.00012(T−Ta)|T−Ta| kW。高温测试再加−0.0005 max(T−65,0)² kW。两个系数是教学构造机制，不是经验材料常数。

参考积分器DOP853，rtol=1e-11、atol=1e-12；部署积分器采用解析线性或单步RK4。只对指定时长、步长与参数范围完成核验，不保证任意刚性系统的数值精度。

开发接口只使用power、ambient、observed。参考温度用于测试评分和图中展示；拟合与选参不读取它。完整数据保存了参考字段，复用时必须继续约束访问范围。
